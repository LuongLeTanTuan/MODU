# MODU - Tự Thiết Kế, Tự Thể Hiện

Trang web giới thiệu & trải nghiệm tùy biến bình giữ nhiệt cá nhân hóa **MODU**.

## ✨ Tính Năng Nổi Bật

1. **Hero Interactive 3D/Canvas Animation:**
   - Trực quan hóa cánh tay cầm bình giữ nhiệt tương tác mượt mà.
   - Chế độ xem Lifestyle & Studio chuyên nghiệp.

2. **Studio Customizer 2.0 (Bộ Công Cụ Tùy Biến Trực Quan):**
   - **Form dáng:** Bình 500ml thon gọn & 750ml có quai xách thể thao.
   - **Màu sắc:** 5 tông màu thời thượng (Xanh Sage, Trắng Mây, Hồng Blush, Xanh Trời, Đen Obsidian).
   - **Khắc tên laser:** Preview thời gian thực 60FPS với 3 kiểu font (Outfit Bold, Chữ ký thanh lịch Script, Bebas Neue) kèm các biểu tượng tối giản (`♥`, `★`, `✦`, `●`).
   - Tùy chọn vị trí khắc: Dọc thân bình hoặc Ngang đế bình.

3. **Khui Túi Mù Charm (Blind Box Experience):**
   - Trải nghiệm xé túi mù 3D với âm thanh xé túi & hiệu ứng bung charm sống động.
   - Bộ sưu tập 8 mẫu charm giới hạn Series 01 (Pastel Bear, Coquette Bow, Clover Luck, Chill Coffee, Y2K Heart, Daisy Sunflower, Lucky Cat, và Secret Diamond).
   - Khả năng gắn thử charm trực tiếp lên quai/nắp bình trong Studio.

4. **Giỏ Hàng & Đặt Hàng Trực Tuyến:**
   - Drawer giỏ hàng lưu đầy đủ cấu hình cá nhân hóa (dung tích, màu sắc, nội dung khắc laser, charm đính kèm).
   - Modal thanh toán và đặt hàng nhanh chóng.

## 🚀 Cách Chạy Dự Án

Dự án được xây dựng hoàn toàn bằng **HTML5, CSS3 và Vanilla JavaScript**, không cần cài đặt dependencies phức tạp:

1. Tải về hoặc clone repository:
   ```bash
   git clone https://github.com/LuongLeTanTuan/MODU.git
   ```
2. Mở trực tiếp file `index.html` bằng trình duyệt web bất kỳ (Chrome, Edge, Brave, Safari, v.v.).
3. Hoặc chạy qua một local static server (ví dụ `Live Server` trên VS Code hoặc `npx serve .`).

## 📁 Cấu Trúc Dự Án

```
MODU/
├── index.html         # Giao diện chính của website
├── style.css          # Toàn bộ hệ thống style & animation
├── script.js          # Logic tương tác tùy biến, âm thanh, túi mù & giỏ hàng
├── assets/            # Hình ảnh bình giữ nhiệt, hero banner & ảnh assets
├── charm/             # 8 mẫu charm chất lượng cao Series 01
└── README.md          # Tài liệu giới thiệu dự án
```
