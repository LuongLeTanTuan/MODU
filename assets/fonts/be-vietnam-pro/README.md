# Be Vietnam Pro

Full-character font files (weights 300–900) downloaded from the Google Fonts repository:
https://github.com/google/fonts/tree/main/ofl/bevietnampro

Designed by Lâm Bảo, Tony Le and ViệtAnh Nguyễn. Project:
https://github.com/bettergui/BeVietnamPro

Distributed under the SIL Open Font License 1.1; see OFL.txt.
These fonts are served locally through the root fonts.css file and retain the complete Vietnamese character set.
